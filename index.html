Act III

Taking Your Seat

Getting a preset onstage takes three steps.

✦
I.

Import the preset

Open AI Response Configuration, set the API to Chat Completion, and click Import preset.

II.

Bring the regex

Every preset carries its own regex scripts. If SillyTavern doesn’t offer to import them, use the bundle: Extensions → Regex → Import.

III.

Read the program

Open the Read Me prompt at the top of the list. It’s never sent to the model, and it walks you through which toggles to pick.
