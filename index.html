Companion · chat memory

Chat Memory module

The other half of every setting. It sets up the guided-novel format and OOC notes in parentheses, and holds the Intensity dial the status bar reports: [INTENSITY: TENDER + FILTHY], from SIMMER to DEPRAVED. It also includes an optional block that keeps a diabetic character’s Dexcom CGM accurate: silent sensor, alerts on the phone, lows that take real time to treat. Delete that block if your character doesn’t need it.

Add-on · model correction layer

Opus 4.7 correction layer

Append it to any setting when you’re running Opus 4.7. It pulls the model back from its elevated literary register to the close, raw voice the prompts are written for.

1,877 characters
View ↗
Using them on Janitor.AI
  1. Open a chat with your bot and go to its API Settings.
  2. Paste the setting into the Custom Prompt box. If you’re on Opus 4.7, paste the correction layer underneath it.
  3. Paste the Chat Memory module into the chat’s Chat Memory, then set the dial whenever you like with [INTENSITY: …].
  4. Every reply opens with a status bar. Impersonate mode is on by default, so the model writes your character too; type [MANUAL: ON] to take the pen back.

Program notes

Taking Your Seat

Getting a preset onstage takes three steps.

✦
I.

Import the preset

Open AI Response Configuration, set the API to Chat Completion, and click Import preset.

II.

Bring the regex

Every preset carries its own regex scripts. If SillyTavern doesn’t offer to import them, use the bundle: Extensions → Regex → Import.

III.

Read the program

Open the Read Me prompt at the top of the list. It’s never sent to the model, and it walks you through which toggles to pick.
