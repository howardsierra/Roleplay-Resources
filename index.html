Presets

Tuned for Claude. Each one has a hostess who narrates the world and, if you let her, comments on it.

Installing a preset
  1. Download the preset .json.
  2. In SillyTavern, open AI Response Configuration, set the API to Chat Completion, and click Import preset.
  3. Regex scripts are bundled inside each preset. If your version doesn't offer to import them, download the regex bundle and use Extensions → Regex → Import.
  4. Open the preset's Read Me prompt at the top of the list for the quick start.

Extensions

Install with Extensions → Install extension and paste the repo URL. The copy button puts it on your clipboard.
